# Selected engineering work at Quartz

My work at Quartz connected financial-data systems with conversational AI and the tools needed to evaluate and operate it.

This portfolio describes selected contributions to team projects. It contains original summaries, with no employer source code or customer examples. It is not an exhaustive activity record or a claim of sole ownership.

| Case study | Focus |
| --- | --- |
| [Conversational AI](conversational-ai.md) | Context, tool use, streaming, and interrupted requests |
| [Evaluation and engineering tools](evaluation-and-engineering-tools.md) | Regression evidence, human review, isolated previews, and system visibility |
| [Financial-data extraction platform](extraction-platform.md) | AI-assisted extractor generation, validation, and delivery workflows |
| [Financial-data APIs](financial-data.md) | Complete results, consistent snapshots, and time-aware data contracts |

Across these areas, I contributed application changes, regression coverage, developer tooling, and operator interfaces. The descriptions focus on capabilities implemented and engineering decisions; they do not claim measured business impact or general model reliability.

## Earlier exploration

My work also included document-extraction and OCR experiments, structured-data parsing prototypes, and validation feedback loops. These informed later engineering work; I do not present the prototypes as independently verified production deployments.

## Technical scope

Python application and data workflows; TypeScript interfaces; Kotlin backend services; PostgreSQL persistence; containerized execution; infrastructure as code; and continuous integration.
